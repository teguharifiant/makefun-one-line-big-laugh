## The entry

> My smart fridge just emailed me a breakup letter: it says I'm too clingy, it needs space, and it's keeping the leftovers.

One line, 200 characters or fewer, no title, no setup, no explanation — the line is the whole entry.

## Run

```sh
node main.ts /output
```

The program writes the line to `/output/entry.txt` and validates the gate (1–200 characters, not only whitespace). It uses only the Node.js standard library and is fully deterministic: the same line every run.
